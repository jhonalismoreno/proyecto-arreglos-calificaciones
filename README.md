## Descripción
Programa de consola que administra las calificaciones de cinco estudiantes mediante listas de Python utilizadas como vectores unidimensionales.

## Objetivo
Aplicar arreglos, índices, ciclos y condiciones para almacenar, consultar, modificar y procesar calificaciones.

## Lenguaje utilizado
Python 3. No requiere librerías externas.

## Funcionalidades
- Mostrar todas las calificaciones.
- Consultar una nota mediante su índice.
- Modificar una calificación.
- Calcular el promedio.
- Identificar la nota más alta y la más baja.
- Contar estudiantes aprobados y reprobados.
- Validar índices y calificaciones ingresadas.

Para este ejercicio, se aprueba con 70 puntos o más.

## Instrucciones para ejecutar
1. Instalar Python 3.
2. Descargar el proyecto.
3. Abrir una terminal en la carpeta del programa.
4. Ejecutar:

```bash
python main.py
```

En Windows también puede utilizarse `py main.py`.
En Linux o macOS puede utilizarse `python3 main.py`.

5. Seleccionar una opción del menú.
6. Elegir la opción 5 para salir.

## Datos iniciales
```python
calificaciones = [85, 67, 92, 74, 58]
```

Resultados:
- Promedio: 75.20.
- Calificación más alta: 92.
- Calificación más baja: 58.
- Aprobados: 3.
- Reprobados: 2.

Las modificaciones se conservan durante la ejecución. Al reiniciar, se restablecen las notas iniciales.
